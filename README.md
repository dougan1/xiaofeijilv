# 消费排班工具 V106

本版本为本地无 CDN 版本，直接打开 `index.html` 即可使用。

主要更新：
- 消费明细改为分类图标 + 名称 + 金额/分类 + 日期 + 垃圾桶删除
- 底部恢复「设置」导航
- 设置页仅保留重要的消费分类、排班设置和数据恢复，周期/金额继续放在对应页面
- 修复每日预计消费：当天预计值锁定，跨天后自动生成新的当天预计值；当天记账后只重算未来日期
- 默认消费分类改为：购物、加油、停车、买菜、餐饮、交通、生活，并支持自定义
- 两个日历表去除重复的具体日期范围
- 去除页面底层灰色背景
