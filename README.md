# 消费排班工具 V8

本版本为本地无 CDN 版本，直接打开 `index.html` 即可使用。

主要更新：
- 消费明细改为分类图标 + 名称 + 金额/分类 + 日期 + 垃圾桶删除
- 底部恢复「设置」导航
- 设置页仅保留重要的消费分类、排班设置和数据恢复，周期/金额继续放在对应页面
- 修复每日预计消费：当天预计值锁定，跨天后自动生成新的当天预计值；当天记账后只重算未来日期
- 默认消费分类改为：购物、加油、停车、买菜、餐饮、交通、生活，并支持自定义
- 两个日历表去除重复的具体日期范围
- 去除页面底层灰色背景

V38：删除排班动画“查看历史/未来班次”提示；进度条下移；夜班改为星空效果。

V41：下班状态隐藏进度条；流星改为左上向右下；优化人物、背包与风的奔跑动效。

V45：修复下班自行车人物消失与骑行动作错乱；人物固定可见，双腿交替蹬踏，车轮和踏板同步循环。


V46 动画素材说明：下班骑行人物改为直接引用公开网页中的循环骑行 GIF，用于替代此前不稳定的自制骑行骨骼动画。素材来源：https://i.pinimg.com/originals/d8/d1/64/d8d1645996dcf0eb683cacc81210c606.gif 。公开页面来源：Pinterest 上的循环骑行贴纸。


V53：新增小车运钱消费彩蛋，内置 SVG/DOM 动画，不依赖外链资源。


V63 数据库连接：已切换到新的 JSONBin Bin。
